# <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/icons/wire-crypto.svg" width="18" height="18" align="absmiddle" alt="" /> Sécurisation des mots de passe dans les scripts Bash sous Linux.

- Comprendre les risques liés au stockage de mots de passe dans les scripts.
- Apprendre différentes méthodes pour sécuriser un mot de passe en Bash.
- Mettre en pratique ces méthodes à travers un TP guidé.

## 1. <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/icons/wire-alert.svg" width="18" height="18" align="absmiddle" alt="" /> Les mauvaises pratiques à éviter
<img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/glow-section-cyan.svg" width="100%" alt="" />

**Ne jamais stocker un mot de passe en clair dans un script Bash !**

<!-- CODE-WINDOW-START -->
> [!CAUTION]
> <img src="https://raw.githubusercontent.com/0xCyberLiTech/0xcyberlitech/main/assets/glow-code-red.svg" width="100%" alt="TERMINAL // BLOC DE CODE" />
>
> ```bash
> #!/bin/bash
> PASSWORD="motdepasse"
> mysql -u root -p$PASSWORD
> ```
<!-- CODE-WINDOW-END -->

**Risque :** N'importe quel utilisateur avec accès au fichier ou à l'historique peut voir le mot de passe.
